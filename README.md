# Expense Tracker

A simple and responsive web-based Expense Tracker built using **HTML, CSS, and JavaScript**.

The application allows users to manage their income and expenses, view financial summaries, filter transactions, and store data using browser Local Storage.

## Features

* Add income and expense transactions
* Enter:

  * Amount
  * Category
  * Date
  * Description
* Edit existing transactions
* Delete transactions
* View total income
* View total expenses
* View current balance
* Filter transactions by:

  * Income / Expense
  * Category
* Data persistence using Browser Local Storage
* Monthly expense summary
* Category-wise expense chart
* Form validation and helpful error messages
* Responsive design for desktop and mobile devices
* Single-page navigation with Dashboard, Add Transaction, Transactions, and Reports sections

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage
* HTML Canvas

## How to Run

1. Clone or download the repository.

2. Open the project folder.

3. Open `index.html` using a local development server such as **VS Code Live Server**.

4. The application will open in your browser.

## Local Storage

The application uses the browser's **Local Storage** to save transaction data.

Therefore, transactions remain available even after refreshing the page or reopening the application in the same browser.

## Main Sections

### Dashboard

Displays:

* Total Income
* Total Expenses
* Current Balance

### Add Transaction

Users can add a new income or expense by entering the amount, category, date, and description.

### Transactions

Displays saved transactions and provides options to:

* Edit transactions
* Delete transactions
* Filter transactions

### Reports

Provides:

* Monthly expense summary
* Category-wise expense visualization

## Validation

The application validates transaction inputs and provides helpful error messages for invalid or incomplete entries.
